# 幻之之技能

在之之的「技能列表 → 云端」中按分类浏览并安装。安装后，技能出现在「技能列表 → 正式」。已有同名技能不会被覆盖。

| 分类 | 技能 | 用途 |
| --- | --- | --- |
| 游戏助手 | [砖了个砖提示](游戏助手/砖了个砖提示/) | 识别棋盘，提示点击或拖动，由你操作 |
| 桌宠互动 | [桌宠排球](桌宠互动/桌宠排球/) | 在桌面上与之之打排球 |

也可以下载本仓库，将分类文件夹内的完整技能目录（如 `游戏助手/砖了个砖提示/`）复制到幻之之的 `tasks/`，不要复制外层分类文件夹。需要当前支持 JSON 技能清单的[幻之之宿主](https://github.com/huanGrass/HuanZhiZhi)，不附带 Python 环境。

源码按 `分类/技能名/` 存放，新增技能放入对应分类目录。

`catalog.json` 提供分类与下载清单；`packages/` 保存按版本制作的技能 ZIP。清单中的下载地址固定到 Git 提交，宿主检查大小和 SHA-256 后安装，不自动运行下载的代码。更新技能时发布新版本；现有本地技能需自行备份后替换。

此仓库只包含公开运行文件、必要资源和说明，不包含内部技能、测试截图或草稿。桌宠排球的音效由代码合成。代码与音效采用 [MIT License](LICENSE)。
