# 桌宠排球

球、球网、四面半透明虚线边框和比分直接浮在桌面上，球场内部透明。鼠标控制左侧圆形球拍，之之本体在右侧用头顶球，双手保持原来的自然姿态。球落在某一方地面，另一方得一分；比分持续累积，按 Esc 或停止任务结束比赛。之之有反应延迟、移动速度限制和少量落点判断误差，接球前会轻微下沉，触球后顶起再回落。

## 开始与操作

在正式技能中选择“桌宠排球”并开始。更新技能后，停止正在运行的排球任务并重新启动即可使用新规则。

- 鼠标在左半场移动球拍，挥动速度和碰撞位置影响回球力度、角度。
- 拖动任意虚线边框移动整个球场；悬停时边框变亮。拖动期间冻结比赛，松手保持原来的运行或暂停状态。
- 球场限制在当前屏幕可用区域内，避开任务栏，并记住拖动后的最终位置。球撞到边界时，对应边框短暂变亮。
- 轮到你时点击场地区域发球。
- 开始时由你先发球，之后由上一球失分方发球。回合结束后，球立即贴在朝向球网的斜上沿（球拍右上侧、之之头部左上侧），等待期间随其移动。之之等待约 1.2 秒后自行顶球发出，轮到你时等待点击。
- 之之准备发球时，暂停、拖动球场或切换到其他应用都会冻结等待时间，恢复后继续等待。
- 空格发球或暂停；暂停后点击场地继续。
- 切换到其他应用时自动暂停；回到场地后点击继续。
- Esc 退出比赛；宿主状态条也能暂停、继续和停止。由宿主暂停时，请在宿主状态条继续。
- 关闭比赛、停止技能、隐藏桌宠或技能异常退出，宿主都会解除接管并恢复之之的位置。显示器设置变化会停止互动。

支持飞碟与扫帚主题，沿用当前桌宠大小；体型过大、无法放进半场时会提示先调小。活动范围会按屏幕可用区域适配。游戏期间场地区域接收鼠标输入，避免点击发球时误点下面的应用；区域外仍可正常操作。游戏不移动系统鼠标，不发送点击或键盘输入，不需要新增依赖或外部服务。

发球、球拍击球、之之顶球、碰网和落地得分各有短音效；得分音效优先，连续碰撞会限频，暂停、拖动和退出会停止播放。得分一侧的数字会短暂放大并着色（你为浅绿、之之为暖黄），随后恢复。

## 实现边界

`physics.py` 保存物理、对手 AI、碰撞和计分；`game.py` 保存球场绘制和鼠标键盘交互；`task.py` 只处理技能入口及结束报告。游戏不导入或修改宿主的窗口对象。

真实角色通过 `TaskSession.acquire_pet()`、`update_pet()`、`release_pet()` 控制；宿主只提供通用接管能力。技能使用待机姿态中的 `head`、`head_radius`、`head_radius_x` 几何信息，把椭圆碰撞范围对齐到之之头部，只允许头部上侧顶球，不切换指向/伸手动作，也不把飞碟或扫帚算作击球部位。回弹由接触点法线与相对速度决定；蓄力、顶起和回落直接移动同一个头部碰撞锚点，避免画面与碰撞脱节。

几何坐标使用 Qt 全局逻辑像素，屏幕缩放由 Qt 处理；不要混入 Win32 物理像素。每帧发布最新角色位置，宿主合并过时位置并按约 60 Hz 绘制。

`sounds/` 内是本技能合成的短 PCM WAV 音效，使用标准库 `winsound` 异步播放，不阻塞 Qt 主循环。物理层输出发球、触球、碰网和得分事件，界面每帧消费一次；音频不可用时仅记录一次日志，比赛照常运行。
